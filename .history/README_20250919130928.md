## DevOps інфраструктура (імітація, без реального підключення до AWS)

Репозиторій містить Terraform-конфігурацію, що моделює повну DevOps-інфраструктуру на AWS із компонентами: VPC, EKS, RDS/Aurora, ECR, Jenkins, Argo CD, Prometheus, Grafana. Конфігурація побудована так, щоб її можна було `terraform validate/plan` без реальних доступів до AWS (локальний бекенд, фіктивні ключі, умовні імена ресурсів на кшталт `chernous_fp_devops-*`).

### Як запустити локальну перевірку

1) Встановіть Terraform 1.5+.
2) У корені репозиторію виконайте:

```bash
terraform init
terraform validate
terraform plan -out=tfplan
```

Стан зберігається локально у `state/terraform.tfstate`.

### Приймальні критерії (без реального AWS)

- Після `terraform plan` ви побачите створення ресурсів із іменуванням:
  - VPC: `chernous_fp_devops-vpc` із public/private сабнетами та NAT
  - ECR: `chernous_fp_devops-ecr`
  - EKS: `chernous_fp_devops-eks`
  - RDS: `appdb` (Postgres 14.10)
  - Jenkins/ArgoCD як `helm_release` з namespaces `jenkins`, `argocd`

### Імітація кластерних перевірок

Оскільки немає реального кластера, команди нижче наведені як еталон перевірки у бойовому середовищі:

```bash
kubectl get all -n jenkins
kubectl get all -n argocd
kubectl get all -n monitoring

kubectl port-forward svc/jenkins 8080:8080 -n jenkins
kubectl port-forward svc/argocd-server 8081:443 -n argocd
kubectl port-forward svc/grafana 3000:80 -n monitoring
```

### Змінні за замовчуванням

Основні змінні задані у `main.tf` з фіктивними значеннями:

- `project_prefix = "chernous_fp_devops"`
- `aws_region = "us-east-1"`
- `aws_access_key`, `aws_secret_key`, `aws_session_token` — фейкові значення для проходження провайдера

### CI/CD (Jenkins + Argo CD)

- Jenkins і Argo CD визначені як `helm_release` у модулях `modules/jenkins` і `modules/argo_cd`.
- Для реального середовища необхідно задати дійсні `kube_host/kube_ca/kube_token`.

### Моніторинг (Prometheus, Grafana)

- Додайте власний модуль/чарт у `modules/monitoring` з Helm-релізами `kube-prometheus-stack` або окремо `prometheus` і `grafana`.
